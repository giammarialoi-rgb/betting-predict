# TASK 044 — Autopsy protocol

After settlement:

1. `PREDICTION_VS_RESULT`
2. Classify CORRECT / INCORRECT / NEUTRAL / UNRESOLVED
3. Failure: root-cause hypotheses (A–O categories) with confidence — not certainty
4. Backward signal search marked `POST_EVENT_ANALYSIS`
5. Counterfactual weight probes — no promotion
6. Success autopsy: CORRECT_FOR_EXPECTED_REASON vs LUCKY_CORRECT etc.

LLM may only summarize computed fields — never invent causes.
