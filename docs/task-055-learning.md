# TASK 055 — Learning loop

## On incorrect settlement

1. **Autopsy** — predicted vs actual, WHY, supporting/contradicting signals, pre-lock evidence only for causal claims
2. **Backward search** — missed signal with `was_available_pre_lock`
3. **Counterfactual** — separate record; does not mutate original prediction
4. **Learning case** — structured lesson + candidate model change
5. **Error patterns** — aggregated frequency / severity / sport / market / model version

## Challengers

MODEL_v3+ stay `OBSERVATION_ONLY`. No auto-promotion.

## Scientific edge gate

`MODEL_EDGE = DEMONSTRATED` only after SETTLED ≥ 100 and TRAIN/VALIDATION/TEST/HOLDOUT with significance. Until then: `UNKNOWN` (never fake NO_DEMONSTRATED_EDGE on tiny n).

## Hindsight firewall

Post-event data may explain errors; it must never rewrite the locked prediction.
